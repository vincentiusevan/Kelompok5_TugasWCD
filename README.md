# NeuroSync — Website Company Profile

Tugas Kelompok mata kuliah Web Client Development, Cakrawala University.

NeuroSync adalah startup fiktif yang membuat platform pemantau ritme kerja untuk
tim remote dan hybrid. Semua data, angka, dan kontak di website ini cuma contoh.

## Teknologi

- Semantic HTML5
- CSS murni, tanpa framework
- JavaScript vanilla, tanpa library
- Huruf Plus Jakarta Sans dan JetBrains Mono dari Google Fonts

## Cara menjalankan

Buka `index.html` langsung di browser, atau lewat server lokal:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.
